# Print layouts

| Piece | Size | Layout |
| --- | --- | --- |
| Travel/expense cover | approximately 220 × 136 mm | Saved worksheet scale 100%, A4 landscape |
| Reception application | approximately 198 × 86.5 mm | Saved worksheet scale 90% |
| Ordinary evidence | 198 × 126 mm | Two rows on portrait A4 |
| Payment image | 96 × 126 mm | Two columns × two rows on portrait A4 |
| Whole Ctrip page | 198 × 66 mm | One column × four rows on portrait A4 |

All evidence is fitted proportionally inside its piece, with internal margins. The source page is not stretched or silently cropped. Review small text in the output before printing. Long non-Ctrip screenshots may need an explicitly recorded derived split when the whole view is unusable; preserve the original and the full content.

For Ctrip flight/hotel invoices, tickets and stay confirmations, use original whole PDF pages with evidence `print_layout:"ctrip_1x4"`. Each original page occupies one row. Four pages share one A4 sheet when available; unused rows remain blank. A multi-page original uses one strip per original page. Do not split a single source page across strips. A pre-cropped Ctrip PDF is rejected rather than silently losing content. Payments retain their separate layout.

Print generated evidence PDFs at **actual size / 100%, one PDF page per physical A4 sheet**, with automatic page orientation. Four-row imposition and cut guides are already in the file; do not apply another four-pages-per-sheet setting. Cut the pieces manually and attach them to the matching cover. A successful PDF check is not a physical printer test.
